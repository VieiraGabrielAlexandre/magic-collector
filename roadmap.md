Features novas

Alta prioridade (uso frequente)
- Scan de carta por câmera — integrar com a API do Google Vision ou com a própria Scryfall image recognition. Cadastrar apontando o celular para a carta.
- (FEITO) Valor total da coleção — já tem price_usd por carta, só falta uma tela/widget que some tudo, filtrável por deck, raridade, cor. 
- Trade list — marcar cartas como "disponível para troca" com quantidade mínima que fica; gera uma lista exportável para postar em grupos.

Média prioridade
- Notificação de preço — "me avisa se essa carta passar de $X" (pode ser um cron Lambda + e-mail simples).
- Deck comparison — comparar dois decks lado a lado: cores, curva de mana, tipos, preço total.
- Importar da Moxfield / Archidekt — essas plataformas têm URLs públicas de deck; um scraper simples permitiria importar sem digitar nada.
- (INTERESSE) Sleeve / storage tracker — onde fisicamente cada carta está (pasta A, caixa B, sleeve de deck X). Simples, mas muito pedido por colecionadores sérios.
